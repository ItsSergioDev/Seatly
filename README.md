# Seatly

Aplicación educativa full stack para explorar películas y sesiones, seleccionar butacas y gestionar reservas.

## Objetivos

- Aprender Angular y desarrollo frontend.
- Aprender NestJS y diseño de APIs.
- Trabajar con PostgreSQL, SQL y transacciones.
- Practicar testing, Git, GitHub y documentación.
- Aprender a tomar y justificar decisiones técnicas en equipo.

## Estructura

- `apps/`: aplicaciones ejecutables.
- `libs/`: librerías internas.
- `drizzle/`: migraciones y datos iniciales.
- `docs/`: documentación.
- `docker/`: configuración de contenedores.
- `tools/`: scripts y herramientas.
- `.github/`: automatización y colaboración.
